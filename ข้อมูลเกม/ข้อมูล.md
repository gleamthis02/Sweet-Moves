# 🍬 Sweet Moves — สรุปโปรเจกต์สำหรับนำเสนอ

> เกมเว็บแอปแนวด่าน (Candy Crush style) ที่ผู้เล่น **ใช้ร่างกายเล่นผ่านกล้องหน้า** — ทำท่าทางตามภารกิจ ระบบตรวจจับท่าด้วย AI แล้วนับผลให้อัตโนมัติ

---

## 1. ภาพรวมโปรเจกต์

| หัวข้อ | รายละเอียด |
|---|---|
| ชื่อเกม | **Sweet Moves** |
| ประเภท | เว็บแอปเกม เข้าร่วมการแข่งขันเกมเว็บแอป |
| ธีม | โลกขนมหวานสดใส โทนสีอ่อน ไม่ฉูดฉาดจนแสบตา |
| จุดเด่น | เล่นด้วย **ท่าทางร่างกายจริง** ผ่านกล้อง ไม่ต้องใช้คอนโทรลเลอร์ |
| รูปแบบหน้าจอ | แนวตั้งอัตราส่วน 9:16 (เหมาะกับมือถือ) |

**แนวคิดหลัก:** เปลี่ยนการออกกำลังกายง่าย ๆ ให้เป็นเกมสนุก ผู้เล่นผ่านด่านด้วยการทำท่าตามภารกิจ สะสมดาว แข่งอันดับประจำเดือน

## 2. เทคโนโลยีที่ใช้ (Tech Stack)

อ้างอิงจาก `package.json` (ชื่อแพ็กเกจ `sweet_moves`)

| เทคโนโลยี | ใช้ทำอะไร |
|---|---|
| **React** | สร้างหน้าจอ (UI) แบบแบ่งเป็นคอมโพเนนต์ จัดการสถานะของเกม เช่น ด่านปัจจุบัน ดาว เวลา |
| **Vite** (+ `@vitejs/plugin-react`) | เครื่องมือ build และ dev server ที่เร็ว รัน `npm run dev` แล้วเห็นผลทันที |
| **MediaPipe Tasks Vision** (`@mediapipe/tasks-vision`) | AI ตรวจจับท่าทางร่างกาย (Pose Detection) จากภาพกล้องแบบเรียลไทม์ ทำงานบนเบราว์เซอร์ |
| **Firebase** (Authentication + Firestore) | ระบบผู้ใช้ และฐานข้อมูลเก็บคะแนนเพื่อทำ Leaderboard ประจำเดือน |
| **ESLint** | ตรวจคุณภาพโค้ด |

**สคริปต์ที่ใช้:** `dev` (รันตอนพัฒนา), `build` (สร้างไฟล์สำหรับใช้งานจริง), `lint` (ตรวจโค้ด), `preview` (ดูตัวอย่างหลัง build)

## 3. หลักการทำงานของระบบตรวจจับท่าทาง

ไฟล์หลัก: `src/poses.js` (มีคลาส `PoseTracker`) เก็บท่าทั้งหมด **25 ท่า**

**ขั้นตอนการทำงาน (อธิบายแบบภาพรวม)**

1. เปิดกล้องหน้าเมื่อเริ่มเล่นด่าน
2. ส่งภาพจากกล้องเข้า MediaPipe ทีละเฟรม
3. MediaPipe คืนค่า **จุดสำคัญของร่างกาย (landmarks)** เช่น ไหล่ ข้อศอก ข้อมือ สะโพก เข่า ข้อเท้า เป็นพิกัดบนภาพ
4. `PoseTracker` นำพิกัดมาคำนวณ เช่น เปรียบเทียบตำแหน่งข้อมือกับศีรษะ หรือมุมของข้อต่อ เพื่อตัดสินว่า "ตอนนี้อยู่ในสถานะท่าไหน"
5. การนับครั้งใช้หลัก **เปลี่ยนสถานะครบรอบ** เช่น ท่ายกแขนเหนือศีรษะ ต้อง *ลดแขนลง* แล้ว *ยกขึ้นอีกครั้ง* จึงนับเป็น 1 ครั้ง (กันการนับซ้ำจากการค้างท่า)
6. หน้าจอแสดงข้อความบอกผู้เล่นว่าตอนนี้อยู่สถานะไหนและต้องทำอะไรต่อ รวมถึงข้อความ "ถอยออกมา" เมื่อยังเห็นตัวไม่ครบ

**ท่าทางแบ่งเป็น 4 กลุ่ม:** แขน / ขา / แกนกลางลำตัว / ทั้งตัว โดยออกแบบให้ง่ายต่อการตรวจจับด้วยกล้อง และแบ่งระดับความยาก **ง่าย / กลาง / ยาก** (ระดับความยากไม่แสดงให้ผู้เล่นเห็น)

## 4. ระบบเล่นเป็นด่าน (Level System)

### 4.1 โหมดแบบจับเวลา
- แต่ละด่านมีหลายเควส แต่ละเควสมี **เวลาจำกัด**
- เควสถูกสุ่มจากท่าทั้ง 25 ท่า โดยเลือกเฉพาะระดับความยากที่เหมาะกับด่านนั้น
- เมื่อตรวจจับว่าทำท่า **ถูกต้อง** = เควสผ่าน (ระบบจำผลไว้เงียบ ๆ ไม่แสดงให้ผู้เล่นเห็น)
- เควสจะจบเมื่อ **หมดเวลา** เท่านั้น แล้วเสียงเควสจะเล่นตอนเควสถัดไปเข้ามา
- ผู้เล่นกด **ข้าม** เควสได้ โดยไม่เสียดาว เควสที่ข้ามจะนับเป็น "ไม่ผ่าน"

### 4.2 กติกาแต่ละช่วงด่าน

| ด่าน | จำนวนเควส | เวลาต่อเควส | ระดับท่าที่สุ่ม |
|---|---|---|---|
| 1–3 | 2 | 15 วินาที | ง่าย |
| 4–6 | 3 | 20 วินาที | ง่าย + กลาง |
| 7–13 | 4 | 25 วินาที | ง่าย / กลาง / ยาก |
| 14–20 | 5 | 25 วินาที | ง่าย / กลาง / ยาก |
| 21 ขึ้นไป | 6 | 30 วินาที | ง่าย / กลาง / ยาก |

### 4.3 การให้ดาวตามสัดส่วนเควสที่ผ่าน

| เควสที่ผ่าน | ดาวที่ได้ |
|---|---|
| 0 เควส | 0 ดาว |
| 1–19% | 1 ดาว |
| 20–39% | 2 ดาว |
| 40% ขึ้นไป | 3 ดาว |

- เริ่มด่านที่ 0 ดาว แล้วดาวบนหน้าจอ **ค่อย ๆ เพิ่มแบบสดตามสัดส่วนเควสที่ผ่านถึงเกณฑ์**
- ด่านจะ **ปลดล็อกทีละด่าน** ต้องผ่านด่านก่อนหน้าจึงเปิดด่านถัดไป ด่านที่ล็อกแสดงเป็นสีเทา

## 5. ระบบอื่น ๆ ในเกม

### 5.1 ชาเล้นท์ประจำวัน (Daily Challenge)
- ใช้รูปแบบจับเวลา 60 วินาที
- สุ่ม 3 ชาเล้นท์ ต่อวันให้ผู้เล่นได้ท้าทายตัวเอง
- ถ้าทำท่าตรงในเวลาที่กำหนดได้รับดาวดังนี้
  0 ดาว (ไม่ผ่าน) ทำท่าตรง 0-1 ครั้ง
  1 ดาว (ผ่าน) ทำท่าตรง 2-9 ครั้ง
  2 ดาว (ผ่าน) ทำท่าตรง 10-19 ครั้ง
  3 ดาว (ผ่าน) ทำท่าตรง 20 ครั้งขึ้นไป
- ท่าทางที่มีในชาเล้นท์
  กระโดดตบ
  ขยับขาเหมือนเดิน 
  ชกซ้ายขวา
  ก้มแตะเข่ายืดตรง 
  ตบมือเหนือหัว

### 5.2 ภารกิจประจำวัน (Daily Quests)
- สุ่มมา **3 ภารกิจต่อวัน** รีเซ็ตทุกวันใหม่ ทำสำเร็จแต่ละภารกิจได้ **ดาวน้ำเงิน 1 ดวง**
- คลังภารกิจ:
  - ได้ 3 ดาวใน 1 ด่าน
  - ได้ 2 ดาวขึ้นไปใน 2 ด่าน
  - ได้ 2 ดาวขึ้นไปใน 3 ด่าน
  - ออนไลน์เกิน 10 นาที
  - ออนไลน์เกิน 15 นาที
  - เล่นชาเล้นท์ของวันนี้ 2 ครั้ง
  - เล่นชาเล้นท์ของวันนี้ 1 ครั้ง
  - เล่นชาเล้นท์ใดก็ได้ 1 ครั้ง

### 5.3 อันดับประจำเดือน (Leaderboard)
- จัดอันดับจาก **ดาวน้ำเงินสะสม** ที่ได้จากภารกิจประจำวัน
- **รีเซ็ตทุกเดือน** แสดง Top 10 ที่แท็บอันดับ
- เก็บข้อมูลบน **Firebase (Firestore + Authentication)**
- แต่ละแถวแสดงชื่อผู้เล่นฝั่งซ้าย และคะแนนพร้อมไอคอนดาวน้ำเงินฝั่งขวา

### 5.4 ไอเท็มจากหีบสมบัติ (ยังไม่ได้ทำ แนวคิดอนาคต)
| ไอเท็ม | ผลที่ได้ |
|---|---|
| 🧊 โล่น้ำแข็ง | ถ้าขาดเล่นหนึ่งวัน ตัวคูณที่สะสมไว้จะไม่หาย |
| 🪣 ถังลาวา | รีเซ็ตภารกิจประจำวันทันที |
| 👟 รองเท้ากระโดด | ข้ามด่านได้ (ด่านที่ข้ามไม่ได้ดาว) |

### 5.5 เสียงประกอบ
- เสียงกดปุ่ม UI ทุกปุ่ม
- เสียงตอนกดข้ามระหว่างเล่น
- เสียงทุกครั้งที่นับท่า (rep) และเมื่อเควสสำเร็จ
- เสียงชนะ เฉพาะหน้าสรุปผลเมื่อได้มากกว่า 1 ดาว

## 6. โครงสร้างหน้าจอ (UX/UI Flow)

| หน้าจอ | รายละเอียด |
|---|---|
| **แผนที่ด่าน (Stage Map)** | เลื่อนแนวนอนจากซ้ายไปขวา ปุ่มด่านวางตามเส้นทางหญ้า มี 3 ฉาก: Stage (ด่าน 1–10), Desert (11–20), Snow (21–30) รวม **30 ด่าน** เชื่อมกันด้วยการเบลนภาพให้ต่อเนื่อง ขอบซ้ายสุดและขวาสุดไล่เป็นสีดำ และจำตำแหน่งเลื่อนล่าสุดเมื่อกลับมาจากหน้าอื่น |
| **ป็อปอัปด่าน** | แสดงรายละเอียดด่าน ดาวที่ได้ และ "เวลาที่ทำได้" (เวลาที่เร็วที่สุดที่เคยเล่นจริง หรือ "-" ถ้ายังไม่เคยเล่น) |
| **หน้าเล่นเกม (In-game)** | กล่องภารกิจด้านบน ("ด่านที่ X - เควสที่ n/total", ชื่อท่าและจำนวนครั้ง, ดาว 3 ดวง, ปุ่มข้าม) กล้องขนาดใหญ่ตรงกลาง และเวลาที่ใช้ที่มุมขวาล่าง |
| **หน้าสรุปผล** | แสดงดาวที่ได้ "ได้รับ x ดาว!", "ทำเควสสำเร็จ: x/y", เวลาที่ใช้ ปุ่ม "กลับสู่เมนูหลัก" และ "ดูภารกิจประจำวัน" |
| **แถบนำทางล่าง** | มี 2 แท็บ คือ อันดับ (icon_rank) และภารกิจ (icon_mission) |
| **หน้าภารกิจประจำวัน** | เปิดจากแท็บภารกิจ ใช้แบนเนอร์ Title.png |
| **หน้าอันดับ** | ใช้แบนเนอร์ Title.png ตำแหน่งเดียวกับหน้าภารกิจ มีข้อความ "อันดับประจำเดือน" |
| **ตั้งค่า** | ไอคอนตั้งค่ามุมซ้ายบนทุกหน้า กดแล้วเปิดแผงตั้งค่า มีสวิตช์เปิด/ปิด และปุ่มออกจากระบบ |

## 7. ทรัพยากรภาพ (Assets)

ไฟล์ภาพทั้งหมดอยู่ใน `/src` และนำเข้าด้วยโค้ด (ไม่ใช่ `/public`) ชื่อโฟลเดอร์และไฟล์แยกตัวพิมพ์เล็ก-ใหญ่

| โฟลเดอร์ | เนื้อหา |
|---|---|
| `background/` | พื้นหลังป็อปอัป กล่องภารกิจ แถบล่าง ป้ายชื่อ รายชื่อผู้เล่น (เช่น Background_Stage, Background_Mission, Title, List_Player) |
| `Button/` | ปุ่มต่าง ๆ (button, squard_red, squard_gray, Open, Close) |
| `icons/` | ไอคอน เช่น ดาว (ทอง/เทา/น้ำเงิน) หัวใจ ภารกิจ อันดับ ตั้งค่า โปรไฟล์ |
| `wallpaper/` | ฉากแผนที่แบบพาโนรามา (Stage, Desert, Snow) และวอลเปเปอร์ของหน้าอื่น ๆ |

## 8. สถานะความคืบหน้า

**ทำแล้ว / กำหนดดีไซน์แล้ว**
- ออกแบบ UI ครบ และกำหนดรูปแบบการเล่นทั้งหมด
- โครงโปรเจกต์ React + Vite พร้อม MediaPipe และ Firebase
- ระบบตรวจจับท่า 25 ท่า พร้อมระบบนับแบบเปลี่ยนสถานะครบรอบ
- ระบบด่านแบบจับเวลา การให้ดาว และการปลดล็อกทีละด่าน
- แผนที่ 30 ด่าน 3 ฉาก
- โครงชาเล้นท์ประจำวัน ภารกิจประจำวัน และ Leaderboard

**ยังเป็นเพียงโครง (ยังไม่ทำงานจริง)**
- ปุ่ม "ดูภารกิจประจำวัน" บนหน้าสรุปผล
- สวิตช์ในแผงตั้งค่าและปุ่มออกจากระบบ

## 9. โครงสไลด์ที่แนะนำสำหรับนำเสนอ

1. **หน้าปก** — Sweet Moves: เล่นเกมด้วยร่างกายของคุณ
2. **ปัญหาและแนวคิด** — ทำให้การขยับตัวสนุกเหมือนเล่นเกม
3. **Demo ภาพรวม** — แผนที่ด่าน → เล่นผ่านกล้อง → สรุปผล
4. **เทคโนโลยี** — React, Vite, MediaPipe, Firebase
5. **AI ตรวจจับท่าทาง** — landmarks → คำนวณ → นับครั้ง (ใช้ไดอะแกรม)
6. **ระบบด่านและดาว** — ตารางกติกาและเกณฑ์ดาว
7. **ระบบประจำวัน** — ชาเล้นท์ ภารกิจ และดาวน้ำเงิน
8. **Leaderboard และ Firebase** — การแข่งขันรายเดือน
9. **ไอเท็มและเสียง** — เพิ่มความสนุกและความรู้สึกตอบสนอง
10. **ดีไซน์ UX/UI** — ธีมขนมหวาน สีสบายตา
11. **สิ่งที่จะพัฒนาต่อ** และ **สรุป**

## 10. คำถามที่อาจโดนถามและแนวตอบ

- **ทำไมใช้กล้องแทนปุ่ม?** → ให้เกมเกิดการเคลื่อนไหวจริง แตกต่างจากเกมทั่วไป และเล่นได้เลยโดยไม่ต้องมีอุปกรณ์เสริม
- **ระบบรู้ได้อย่างไรว่าทำท่าถูก?** → MediaPipe ให้พิกัดจุดร่างกาย แล้วโค้ดเปรียบเทียบตำแหน่งและมุมกับเงื่อนไขของแต่ละท่า
- **ป้องกันการนับซ้ำอย่างไร?** → ต้องเปลี่ยนสถานะครบรอบ (ลดลงแล้วยกขึ้น) จึงนับเป็น 1 ครั้ง
- **ข้อมูลผู้เล่นเก็บที่ไหน?** → Firebase (Authentication สำหรับผู้ใช้ และ Firestore สำหรับคะแนน)
- **เกมยากเกินไปไหม?** → ด่านต้นใช้เฉพาะท่าง่าย เวลาและจำนวนเควสค่อย ๆ เพิ่มตามด่าน และการข้ามไม่เสียดาว
